# Interior Render

A single-page microsite for one widescreen interior-render flythrough. Dusk over a marina tower, then the residence. No build step. This folder is the static site GitHub Pages serves.

**Live path:** https://marc129.github.io/vsh-demo-sites/site-70-interior-render/

The hero is `videos/hero.mp4` (16:9, muted, looping, `playsinline`) with `images/poster.jpg` as the poster frame.
