# Solenne Headland

Fictional cliffside listing site for VSH Media to pitch real-estate agents. Inspired by a luxury Instagram reel. Original name, original layout, Unsplash photography. Not a real property and not affiliated with any estate called Aurelia.

**Live path:** https://marc129.github.io/vsh-demo-sites/site-68-solenne-headland/

No build step. This folder is the static site GitHub Pages should serve. Open `index.html` or serve the folder.

Scroll sequence: hero wordmark, sticky Interior / Mooring / Arrival / Airside, headland editorial, rooms and the 1 466 figure, a dark day from 06:40 to 22:00, September 2026 handover, agent CTA. The CTA links to the VSH studio. It does not collect a name or an email.

A desktop pointer shows a circle cursor, a glass lens on the editorial type, and a magnifier on the handover photograph.
